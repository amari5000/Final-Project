## Project Requirements

## Project Name

## Smart Classroom Comfort Monitor

## Purpose
The purpose of this project is to monitor classroom comfort by allowing users to enter temperature readings and determine whether the temperature is within an acceptable range.

## Functional Requirements
The program must allow users to manually enter temperatures in Fahrenheit.
The default acceptable temperature range must be 68°F to 76°F.
The program must display NORMAL when the temperature is within range.
The program must display WARNING when the temperature is outside the range.
The program must calculate and display the average temperature.
The program must store temperature readings.
The program must save readings to a CSV file.
The program must allow users to change the acceptable temperature range.
The Raspberry Pi must use a GPIO-controlled LED as a warning indicator.

## Hardware Requirements
Raspberry Pi 4 Model B
LED
220-ohm resistor
Breadboard
Jumper wires

## Software Requirements
C programming language
GCC compiler
Raspberry Pi OS
pigpio library
